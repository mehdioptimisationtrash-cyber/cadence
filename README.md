# Cadence

PWA (iPhone + Mac) pour composer des progressions d'accords, harmoniser et générer des mélodies — dans l'esprit de Scaler / Chord Wizard. Vanilla JS, aucun build, sons synthétisés (Web Audio), fonctionne hors ligne, export MIDI.

- Lancer en local : `npm run serve` puis http://localhost:8777
- Tests : `npm test` (unitaires) · `node tests/e2e-flow.mjs <dossier> webkit` (parcours complet, Playwright)
